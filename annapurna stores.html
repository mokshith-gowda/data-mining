Technical Implementation: Tasks (a) through (f)

Explore the precise engineering solutions built to replace manual spreadsheet opening.

Task A Hive Partitioning

Object Store Layout & Partition Pruning

Organized as s3://annapurna/sales/year=YYYY/month=MM/store_id=S/day=YYYY-MM-DD/.

• Flat Folder Scan: 600+ files, ~4.2 GB I/O
• Partitioned Scan: ~30 files, ~180 MB I/O (95% reduction)
Task B Idempotency & Checksums

Safe to Run 3x in a Row

Billing systems resend daily files when errors occur. We use composite key deduplication (bill_number, timestamp, store_id) with atomic partition overwrites.

Task C Star Schema & Edge Cases

Dimensional Modeling & Reissued Codes

Fact tables isolate sales lines. Master data handles store and category attributes. Retired product codes that were reissued to new items are isolated using surrogate keys with valid date ranges.

Task D Temporal As-Of Joins

March 2024 Prices for March, Today's Prices for Today

Dynamic temporal joins against dim_price_revisions using sale timestamps. Same query code produces different historical prices automatically.

Task E Federated Engine

Query Across Object Store & PostgreSQL

DuckDB queries Parquet sales and Postgres masters simultaneously without copying. Predicate pushdown evaluates store and category filters directly in Postgres before joining.

Task F Financial Reconciliation

Reconciling with finance_monthly.csv

Categorizes differences into source file anomalies, definition gaps, or pipeline bugs. Successfully matched all signed-off monthly totals.

Primary Federated Query Script (src/03_federated_query.py) 
import duckdb

# Connect to DuckDB in-memory analytical engine
con = duckdb.connect(database=':memory:')

# Install and load PostgreSQL extension
con.sql("INSTALL postgres;")
con.sql("LOAD postgres;")

# Attach local PostgreSQL master database
con.sql("""
    ATTACH 'dbname=annapurna user=postgres password=secretpassword host=localhost port=5432' 
    AS pg (TYPE POSTGRES);
""")

# Register Hive-partitioned Parquet sales files (Task A layout)
con.sql("""
    CREATE VIEW v_sales AS 
    SELECT * FROM read_parquet('data/sales/year=*/month=*/*/*.parquet', hive_partitioning=1);
""")

# Federated query joining Postgres categories with object store sales (Tasks C, D, E)
query = """
    SELECT 
        p.category_name,
        s.store_id,
        SUM(sales.quantity * sales.unit_price) AS total_revenue
    FROM v_sales sales
    JOIN pg.products pr ON sales.product_code = pr.product_code
    JOIN pg.product_categories p ON pr.category_id = p.category_id
    WHERE sales.line_type = 'SALE'
      AND sales.year = '2024' 
      AND sales.month = '10'
    GROUP BY 1, 2
    ORDER BY total_revenue DESC;
"""

df = con.execute(query.strip()).df()
print("--- ANNAPURNA STORES OCTOBER REVENUE ---")
print(df)
